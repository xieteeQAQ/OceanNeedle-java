    > add [options]

        描述
            新增数据。管理员目前可以新增书籍, 其他对象暂未全部开放。

        [options]
            -o, --object <object>
                目前命令行支持:
                    book       书籍

                省略时会进入交互式选择。

        交互模式
            选择 [1] 学生 或 [2] 书籍; [3]~[5] 暂未开发。
            注意: 命令行的 -o 参数目前只接受 book。

        书籍输入项
            ISBN-13     13 位
            书名        最长 255 个字符
            作者        最长 100 个字符
            是否借出     输入“是”或“否”; 直接回车默认可借

        示例
            add -o book
            add

        权限
            管理员: add -o book
            学生:   无
