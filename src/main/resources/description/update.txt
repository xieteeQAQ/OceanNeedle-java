    > update [options]

        描述
            更新学生或书籍信息。管理员可用。
            学生可以修改密码和手机号; 书籍只修改书名和作者。
            输入时直接按回车表示保留原值; 没有任何变化时会提示“没有数据更新”。

        [options]
            -o, --object <object>
                指定要更新的对象:
                    student    学生
                    book       书籍

                省略时会询问要更新的对象。

            -k, --key <key>
                学生: 12 位学号
                书籍: 书籍编号(正整数)
                省略时会在交互中询问。

        说明
            书籍的可借状态由借阅/归还流程维护, 管理员不能手动修改。

        示例
            update -o student -k 202400010012
            update -o book -k 1

        权限
            管理员: update -o student / update -o book
            学生:   无
